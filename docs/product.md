# プロダクトの方向性

## GuildHubとは

GuildHubは、FF14の固定活動を中心としたDiscordコミュニティ向けの運営支援Botである。単なる日程調整Botではなく、Discordサーバー内の活動をまとめる「Hub」として、固定活動やコミュニティ運営に必要な機能を集約することを目指す。

## 想定する用途

- 固定活動の日程調整
- 出欠確認
- リマインダー
- 投票
- 募集
- 連絡事項
- 攻略活動の進捗管理
- メンバー管理
- オフ会や食事会など、レイド以外の予定調整
- 将来的な活動履歴や各種記録

## 最初の機能: スケジュール調整

想定する基本フロー:

1. ユーザーがDiscord上で予定を作成する
2. 候補日時を複数登録する
3. メンバーが各候補日時に対して回答する
4. 回答状況をDiscord上で確認する
5. 必要に応じて予定を確定する
6. 開催前にリマインドする

Discordネイティブな操作体験を優先し、Application Commands、Components V2(Buttons / Select Menus / Modals)を用いる。Discord Activityの採用は現時点では見送り、Componentsだけでは操作性が不足すると判断した場合の将来的な選択肢とする。

## 設計上のスタンス

- FF14を最初の対象とするが、内部設計はFF14固有の概念へ強く依存させない。将来的に他ゲームや一般的なDiscordコミュニティでも使える余地を残す
- ただし、現時点で過剰な汎用化は行わない
- セルフホストが簡単であることを重視する(単一コンテナ、`docker compose up -d` だけで動く)
- 初期段階では単一プロセス・単一コンテナを基本とし、大規模な運用基盤は前提にしない
